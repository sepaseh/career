## Keeping Profile Content Consistent

[About](about.md) describes my current focus on AI-assisted engineering. The [Software Engineer Resume](resume-software-engineer.md) presents my work on coding assistant workflows alongside my experience in requirements analysis, frontend architecture and software delivery.

Experience and project records hold the underlying facts. [Skills](skills.md) groups the broader practical capabilities, and the [Frontend Engineer Resume](resume-frontend-engineer.md) emphasizes frontend architecture and development. [The LinkedIn reference](linkedin.md) is the source of truth for the intended profile fields: Intro, Contact Info, About, Featured, Experience, Education, Projects, Skills, Courses and Languages. It has a corresponding [Persian version](fa/linkedin.md); publication notes and source links are separated from profile copy at the end.

Update the underlying facts first, then the affected English and Persian skills, resume and LinkedIn files. Keep the same skill identities and order across both LinkedIn references, preserve intentional wording differences from the resume, and record the date of any live-profile review. Regenerate published resume PDFs when their supported Markdown sources change using [the exporter](scripts/README.md). Editing the LinkedIn references does not publish changes to the live profile.
