# برنامه‌ریزی منابع سازمانی

## معرفی

این پروژهٔ در حال توسعه شامل بازسازی فرانت‌اند یک سامانهٔ قدیمی برنامه‌ریزی منابع سازمانی (ERP) به‌صورت پنل مدیریتی مبتنی بر React است. برنامهٔ موجود با ASP.NET MVC و jQuery ساخته شده بود و چون مستندات محصول در اختیارم نبود، برای شناخت صفحات و قراردادهای سرویس، خود سامانه و رفتار APIهای آن را بررسی کردم.

تمرکز کار بر پیاده‌سازی صفحات و گردش‌کارهای ERP بر پایهٔ APIهای موجود بوده است؛ در مواردی که سرویس‌های فعلی نیاز فرانت‌اند را پوشش نمی‌دادند، تغییر قرارداد API را با توسعه‌دهندهٔ بک‌اند هماهنگ کردم.

---

## چالش‌های مهندسی

- استخراج رفتار صفحات و نیازهای یکپارچه‌سازی از سامانهٔ قدیمی، بدون مشخصات محصول.
- کار با مجموعه‌ای از APIها که در ابتدا دسته‌بندی مناسبی نداشتند و برخی از endpointهای آن‌ها خطای سرور می‌دادند یا پارامترها و فیلترهای موردنیاز را پشتیبانی نمی‌کردند.
- پیاده‌سازی فرم‌ها و گردش‌کارهای پیچیدهٔ ERP هم‌زمان با روشن‌شدن و به‌روزرسانی قراردادهای فرانت‌اند و بک‌اند.

---

## مشارکت من

- پیاده‌سازی مستقل فرانت‌اند React برای مجموعهٔ فعلی صفحات و گردش‌کارهای ERP، با بررسی سامانهٔ قدیمی و رفتار APIهای موجود برای استخراج نیازمندی‌ها.
- همکاری با توسعه‌دهندهٔ بک‌اند برای دسته‌بندی مستندات Swagger بر اساس ماژول، بخش و صفحهٔ ERP و تعریف کلیدهای صفحه برای مسیرها و مجوزهای فرانت‌اند. سرویس‌های موجود را تست کردم، خطاها را به تفکیک ماژول در سامانهٔ پیگیری issue شرکت ثبت کردم و تغییرات لازم در قرارداد API را درخواست دادم.
- ساده‌سازی چیدمان فرم‌ها و جریان تعامل با Ant Design برای کاهش اقدام‌ها و کلیک‌های غیرضروری کاربر.
- راه‌اندازی کنترل‌های CI در GitHub Actions برای کیفیت کد، تست‌های واحد و قرارداد API، build تولید، تعامل‌ها و دسترس‌پذیری Storybook و سناریوهای انتهابه‌انتهای Chromium.
- ایجاد راهنمای اختصاصی پروژه برای دستیارهای هوش مصنوعی، شامل قواعد کدنویسی و گردش‌کار، دستورالعمل‌های قابل استفادهٔ مجدد و hookهای ایمنی و کیفیت.
- تهیهٔ مستندات فنی فرانت‌اند و نوشتن تست‌ها.

---

## نکات فنی برجسته

- **ارسال تفاضلی انتساب‌های انبار:** Drawerهای انتساب کاربر و کالا به انبار فقط ردیف‌های تازه‌اضافه‌شده یا حذف‌شده را ارسال می‌کنند و ارتباط‌های بدون تغییر را از درخواست کنار می‌گذارند.

- **بازنگری قرارداد API در جریان مهاجرت:** endpointهای قدیمیِ خطادار یا ناکافی را شناسایی کردم و تغییر پارامترها و فیلترهای درخواست را برای پشتیبانی سرویس‌ها از صفحات React هماهنگ کردم.

- **بازسازی بر پایهٔ سامانهٔ موجود:** نیازمندی‌ها و رفتار صفحات را با بررسی برنامهٔ قدیمی MVC/jQuery و در نبود مستندات محصول استخراج کردم.
